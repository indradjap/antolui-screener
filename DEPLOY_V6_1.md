# Deploy V6.1

Recommended Streamlit Community Cloud runtime: **Python 3.12**.

1. Replace the repository contents with this package.
2. Commit to GitHub.
3. Redeploy/reboot the Streamlit app.
4. If the app is currently on Python 3.14, redeploy it with Python 3.12 in Streamlit Advanced settings.
5. Test Single Stock in this order: `BBCA`, `BUMI`, `DEWA`.
6. Then test Quick Pick on the Liquid IDX seed before running Quality 200.

A ticker with 80–219 raw daily bars is accepted but marked **LIMITED history**; long-term MA200-dependent evidence will naturally be weaker.
